# Master Barber Studio

Sitio web premium de barbería construido con React + Vite + Tailwind CSS.

## URL en vivo
https://bryand10.github.io/barberia.github.io/

## Desarrollo local
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

El sitio se despliega automáticamente a GitHub Pages con cada push a `main` (via GitHub Actions).
